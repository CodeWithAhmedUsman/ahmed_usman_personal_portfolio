AHMED USMAN — PERSONAL PORTFOLIO

Files
- index.html: semantic HTML5 page content
- style.css: custom CSS3 styling and responsive layouts
- images/: optional folder for your own image assets

Run
1. Extract the project folder.
2. Open index.html in a browser, or open the folder in VS Code and use Live Server if available.

Important customization
- The project thumbnails are made with CSS, so no extra image or language files are required.
- The contact form is front-end UI only. HTML/CSS alone cannot send messages to you.
- This project uses HTML5 and CSS3 only for website structure and styling; it does not use JavaScript, Bootstrap, Tailwind, or other UI frameworks.
